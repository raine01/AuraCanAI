游戏内面板

卫月插件列表点「打开」弹出主面板,六个页签:

  • 附近玩家:看看周围都有谁(状态/名字筛选,点名字一键复制,可直接加备注)
  • 活点地图:附近玩家的位置一目了然
  • 玩家备注:给玩家记多行备注(绑定角色ID防改名,详见下方)
  • 回忆检索:输入玩家名,自动翻聊天记录并总结你们聊过的话题
  • 行为设置:设定"当 XX 发生时自动做 XX"的规则(详见下方)
  • 演奏:MIDI 自动演奏(详见下方「演奏」段)

另有控制面板:设置 DeepSeek Key、网页服务端口(改后点「重启网页服务」生效,可复制网页地址)、语音播报的开关/音量/语速。

游戏内指令

  • /aca — 打开主面板(保持上次的页签)
  • /aca list — 附近玩家
  • /aca map — 活点地图;/aca map 玩家名 直接定位该玩家
  • /aca search — 回忆检索(没带名字时,自动搜索当前选中的玩家);/aca search 玩家名 直接指定
  • /aca look — 看向最后一个看我的人(最后注视你的玩家);/aca look 玩家名 看向指定玩家
  • /aca note — 查看/编辑当前选中玩家的备注(未选中玩家时打开玩家备注页签)
  • /aca behavior — 行为设置
  • /aca music — 演奏(导入 MIDI 自动演奏,见下方「演奏」段)
  • /aca setting — 打开设置面板(网页端口、语音、DeepSeek API Key 等)
  • /aca macro N — 直接触发 N 号宏(0-99);共享宏用 /aca macro sN

聊天

  • 实时显示游戏里各频道的消息(说话、小队、部队、跨服贝、悄悄话等)
  • 选好频道输入内容即可发送
  • 收到悄悄话时,点消息下的「回复」按钮可以直接回对方(自动带上服务器名,跨服也能回)
  • 哪些频道要显示、要 AI 参与,都在「配置」页设置

语音播报

  • 用 Windows 系统语音把聊天读出来,音量、语速可在游戏内面板调
  • 每个频道可单独设置「播读」,或「只有被发言人注视时播读」
  • 支持关键字播报、屏蔽字过滤(不想听的内容直接过滤掉)
  • 「玩家进出」「注视提醒」也可以在配置页打开语音提醒

玩家备注

给玩家记多行备注(一段话,如"部队管理,擅长合奏""上次一起打过本"等)。备注绑定角色ID(ContentId),玩家改名后依然能找到。

  • 添加/编辑:打开「附近玩家」页签,点玩家行右侧的「添加」/「编辑」按钮(仅面对面——玩家在场时可用),自动切到「玩家备注」页签填写内容
  • 查看/修改/删除:在「玩家备注」页签输入关键字检索(匹配玩家名或备注内容),点击结果行打开编辑框修改或删除
  • 快捷查看:游戏里选中一个玩家,输入 /aca note 直接查看/编辑他的备注
  • 已备注的玩家在「附近玩家」列表名字前会显示 ★ 标记;删除备注时先点「删除」再点「确认删除?」

行为设置

它是什么:设定一些自动规则——游戏里发生某件事时,自动帮你做一件事。比如"有人看我时选中他""我进房区时触发宏"。适合角色扮演时做自动化小动作。

怎么用(推荐,不用学语法):

  1. 行为设置页签点「+ 新增行为」
  2. 在下方描述框里用大白话写想要的效果,例如:
    当龙尾轻轻摇在看我且我在角色扮演中时,5秒后触发3号宏,冷却30秒
  3. 点「生成行为语句」,AI 自动把命令写好并填入上方「行为语句」框
  4. 检查一下没问题,点「保存」就生效了
  • 需要先在游戏内「设置」面板配置 DeepSeek API Key,没配的话生成按钮是灰的
  • 想一次设多条规则?用「并且/同时」或「；」把多个效果写在一段里
  • AI 写好后仍可手动修改,保存前会自动检查语法,有问题会红字提示

手动写(可选):格式就是「动作 + 条件 + 冷却」。一条规则的模板:

trigger 3 when looking_player = 龙尾轻轻摇 cooldown 30

意思是:当 龙尾轻轻摇 在看我时,触发 3 号宏,30 秒内不重复。常用写法:

  • trigger 5 after 3 when enter_player = 龙尾轻轻摇 cooldown 60 — 龙尾轻轻摇来了,3 秒后触发 5 号宏(1 分钟内不重复)
  • trigger 5 after 3,6 when enter_player = 龙尾轻轻摇 cooldown 60 — 同上,但延迟在 3~6 秒间随机(支持小数,如 after 0.5,2)
  • trigger 1,2,3 when anyone_looking cooldown 20 — 有人看我时,依次触发 1、2、3 号宏(执行完前一个再执行下一个;可混用共享宏,如 trigger s1,2)
  • say p 欢迎{last_enter}来到我家! when anyone_enter — 有人进入附近时,在小队频道欢迎ta(变量自动替换成玩家名,变量为空自动跳过)
  • say t 你好呀 when anyone_looking — 有人看我时,悄悄话回复最后私聊我的人(没指定目标就默认发 last_tell)
  • say t 龙尾轻轻摇@红玉海 在吗? when in_housing — 悄悄话发给固定的人(内容开头写 名字@服务器)
  • look when anyone_looking cooldown 10 — 有人看我时,选中最近接触我的人
  • trigger s2 when in_housing and not in_party cooldown 0 — 在 S/M/L 房或公寓内且不在小队时,触发共享宏 2(无冷却)
  • say p 欢迎{last_enter} when anyone_enter need not in_combat — 有人进入附近时欢迎ta;但若进入瞬间我在战斗中,本次直接丢弃(之后出战斗也不会补触发;need 是状态过滤,与写进 when 的 and 不同)
  • trigger 1 when in_combat ; trigger 2 when anyone_leave — 战斗中触发宏 1;有人离开时触发宏 2

小贴士:编辑时勾选「聊天内提示」,动作触发成功时会在聊天栏提示你;「离开时不触发」「战斗中不触发」(均默认勾选):你的状态为「离开」或处于战斗中时,该行为不触发;「角色扮演限制」下拉框:仅角色扮演时触发 / 角色扮演时不触发 / 不做限制(默认),按网页「角色设定」是否选中了当前角色判断。

状态机(两层)

它是什么:让角色根据处境在不同「状态」间切换,每个状态有自己的人设和动作。分两层:

  • 第一层 = 角色状态(心情很糟糕 / 非常开心 / 亢奋 / 受伤中…):由 AI 自由判断切换(switch_mood),不受限制
  • 第二层 = 情景(待机 / 对话…):每个第一层下可以有几个情景;角色只能在当前第一层内切换,且受你设的「路径」限制(都不勾选 = 同状态内不限)
  • 每个情景可绑定一个人设(下面「角色设定」里的角色名);不同情景可以换人设，也可以不选——不选也会说话，只是不演角色

启用开关:说话与否只看顶部「启用状态机」开关。启用后不管当前情景有没有人设，AI 都会回话(有人设=角色表演，无人设=普通聊天)；关闭则回退到旧的「当前角色」。切人设/情景后建议重载插件或切一下状态，让系统提示重建。

动作列表(待机动作):每个情景都有自己的动作列表,每行 = 名称 / 动作(游戏表情名) / 冷却(秒) / 位置。

  • 自动轮换:当前动作停留满「冷却」秒后,自动随机换同情景下的另一个动作(没有别的就一直保持当前);冷却 0 按 30 秒,最小 3 秒
  • 位置:可空。为空就原地做动作;设了位置则先寻路走过去,到位后再做动作。位置可在游戏内导入:点网页该行的「记录位置」,到游戏里站好输入 /aca pos;也可直接用 /aca pos 动作名 指定哪条
  • AI 也可以主动指定动作(工具 rp_idle_action);游戏内测试:/aca idle [动作名]

组队:AI 可用工具 party_action 邀请组队 / 接受邀请 / 退队。游戏内测试:/aca party invite 玩家名、/aca party accept、/aca party leave。邀请/接受用游戏原生接口,失败会回退到 /invite 命令。

怎么用:上方是一张节点图——上半排是第一层(角色状态),下半排是它的第二层(情景),中间虚线分隔;节点之间的虚线是路径。默认示例:第一层「皮下」「皮上」,皮下含「待机/接待」,皮上含「待机/对话」。点节点选中后在下方面板改名称/说明/人设/路径;蓝底 = 当前状态。

保存:编辑即自动保存(停止输入约 0.6 秒后),顶部也有「保存」按钮;在游戏里记录/清空位置后，页面会自动拉回最新数据(不用手动刷新)。当前状态由 AI 切换,网页不用手动切。

AI 动作(自定义表情)

它是什么:给当前角色配一批专属动作,让 AI 在对话中主动做出来(例如“摸头”“行礼”“摇尾巴”)。每个动作 = 依次发送两条游戏命令:/动作名(游戏表情)+ /em 文字(聊天栏里显示的那句话)。

  • 在哪里配:网页「角色设定」→「角色管理」→ 选中角色的「动作列表（AI 可主动执行）」,点「添加动作」新增一行
  • 名称:给你自己看的备注,同时也是 AI 引用该动作时的标识(必填一个易认的名字)
  • 文字:/em 后面的部分,如“轻轻摸了摸<t>的头”;留空则只做表情
  • 动作:游戏内表情名,只填名字就行(如 抚摸 / 行礼 / 打招呼);填了文字时插件会自动补本地化的「动作」/「motion」子命令(表情名是中文就补“动作”、英文命令就补“motion”),这样游戏不会再多出一条官方表情提示;没填文字就不补,保留游戏官方表情文字
  • 每行下面有「实际发送」预览,边填边看最终会发出的命令,不用担心要不要自己写子命令
  • 这两个字段最终都是游戏原生指令(/表情名 与 /em),所以占位符天然可用:<t> 当前选中目标、<me> 自己、<pos> 坐标等,发送时由游戏自行替换
  • AI 如果写了「(动作)」「*神态*」这类括号描写,插件会自动删掉再发送(整句都是描写则不发那一条),所以聊天栏不会出现括号动作——要让角色做动作就配到这份动作列表里
  • 冷却:单位秒(0 = 不限制)。冷却中的动作 AI 会被拒绝并告知剩余秒数,不会重复刷
  • 动作列表跟着角色走:换角色就换一套动作;保存角色配置后即时生效
  • 动手测试:游戏内输入 /aca action 列出当前角色的动作,/aca action 名称 直接做一次

演奏(MIDI)

网页「歌单」页(地址见设置面板)维护歌单:添加 MIDI;每曲可设「预处理」「拆解」「速度」「移调」与演奏轨道(整曲/指定轨,合奏曲另设主辅轨)。播放模式:单曲 / 循环 / 列表 / 随机,支持暂停、继续、停止、上一首/下一首。

需角色持乐器进入演奏模式;合奏需同机双开,辅端为原版客户端、无需安装任何软件。

🎵 合奏(双开)步骤:

  1. 主端(装卫月+本插件)与辅端(原版客户端)都进入游戏,双方角色持乐器并进入演奏模式
  2. 网页「歌单」页选中合奏曲目 → 勾选「合奏」→ 选择主轨/辅轨(单轨曲目辅端自动不演奏)
  3. 点播放:主端演奏自己窗口,辅端由主端向辅端窗口注入按键,两端同刻开始

⚠️ 合奏建议以管理员身份启动卫月端(XIVLauncherCN)

Windows 有UIPI 权限隔离机制:低权限程序不能向更高权限程序的窗口发送按键。若主端(卫月)以低权限方式运行,而辅端(盛趣登录器启动)是普通权限,主端向辅端窗口注入按键会被系统拒绝(症状:主端自己正常演奏,辅端毫无反应)。

  • 推荐:用桌面「XIVLauncherCN(管理员)」快捷方式启动主端(每次启动弹 UAC,点「是」)——管理员权限高于辅端,合奏稳定可靠
  • 若用普通方式启动,需确保主端与辅端权限一致;不要从受限/低权限终端启动 XIVLauncherCN
  • 若合奏时辅端无反应:任务管理器确认两个 ffxiv_dx11 进程权限级别,主端需不低于辅端,重启 XIVLauncherCN 再试

已知限制:辅端(纯原版)状态跨进程不可读,演奏就绪检测仅覆盖主声部(自己),辅端需人工确认已进入演奏模式。
